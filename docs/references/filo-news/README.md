# 📸 Referencias de Estilo - Filo.news

Carpeta para almacenar referencias visuales del estilo editorial Filo.news que se aplicará al contenido de envivo-tandil.

## 📁 Estructura

```
filo-news/
├── reels/          # Referencias de formato Reel (9:16)
├── posts/          # Referencias de posts cuadrados (1:1) y verticales (4:5)
├── stories/        # Referencias de stories (9:16)
└── brand-kit/      # Elementos de marca: logos, paleta, tipografías
```

## 🎨 Qué buscar en las referencias

### Reels (`/reels/`)

- [ ] Apertura/tapa del reel (primer frame)
- [ ] Estilo de transiciones
- [ ] Tipografía en movimiento
- [ ] Uso de color/identidad
- [ ] Duración típica y ritmo

### Posts (`/posts/`)

- [ ] Composición de imagen + texto
- [ ] Posición del título principal
- [ ] Estilo de subtítulos/bajada
- [ ] Filtros o tratamiento de fotos
- [ ] Overlays/gradientes usados
- [ ] Márgenes y espaciados

### Stories (`/stories/`)

- [ ] Diseño de tapas de stories
- [ ] Elementos interactivos (stickers, encuestas)
- [ ] Tipografía en stories
- [ ] Flechas/swipe up indicators
- [ ] Consistencia con posts

### Brand Kit (`/brand-kit/`)

- [ ] Logo o logotipo de Filo.news
- [ ] Paleta de colores principal
- [ ] Paleta de colores secundaria/accentos
- [ ] Tipografías usadas (nombres si son identificables)
- [ ] Elementos gráficos recurrentes (líneas, formas, íconos)

## 📝 Notas para análisis

Cuando guardes las imágenes, agregá un comentario sobre:

1. **Qué te gusta** de esa referencia específica
2. **Dónde la encontraste** (para contexto)
3. **Para qué formato aplica** (si es mixta)

---

**Nota:** Estas referencias son para inspiración y definición del estilo. No se usarán directamente en el sistema, solo como guía para crear los templates.
